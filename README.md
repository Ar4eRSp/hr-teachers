## Как устроен поток данных

```
data/Педагоги.xlsx, Образование.xlsx, ПК-ПП.xlsx, Школы.xlsx
    → prototype/Предобработка и очистка.ipynb
        ├─ data/data_clean.parquet  (подробные предметы и параллели; вход ДЗ8)
        └─ data/teachers.parquet    (одна строка на педагог–год; Dash и будущая модель)
```

Для обновления данных откройте `prototype/Предобработка и очистка.ipynb`, выберите
Python из `.venv` и выполните **Restart and Run All**. Рабочая папка — корень проекта
или `prototype/`. Ноутбук читает четыре исходных Excel, использует очищенные таблицы
в памяти и после проверок сохраняет оба parquet. Для пробной сборки измените
`OUTPUT_DIR` в первой ячейке на временную папку. Исходные Excel не изменяются.

После обновления `teachers.parquet` перезапустите дашборд. Для обычного запуска Dash
достаточно готового parquet; выполнять ноутбук каждый раз не требуется.
Старые работы ДЗ5 сохраняются как история и не входят в обычный маршрут обновления.

Запуск приложения и проверок из корня проекта в PowerShell:

```powershell
.\.venv\Scripts\python.exe dashboard/app.py
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
```

Адрес приложения: http://127.0.0.1:8050.


## Контракт данных: `data/teachers.parquet`

1 строка = 1 педагог (`id`) в 1 году (`year`, 2022–2024). Пара `id, year` уникальна.
Витрина содержит прежние поля дашборда и `experience_age_other_clean` для будущей модели.
В подробной таблице повторения `id, year` ожидаемы: это предметы и параллели.
В кадровой витрине используются названия `n_subjects`, `n_parallels`, а в подробной —
`n_unique_subjects`, `n_unique_parallel`; это соответствующие показатели нагрузки.
Кодирование категорий и масштабирование следует обучать внутри модели, не в этом parquet.

| Колонка | Тип | Смысл |
|---|---|---|
| `id`, `year`, `school_num`, `district` | str, int, int, str | педагог, год, школа, округ (5 округов) |
| `main_position_cat` | str | `учитель` / `руководитель` / `другой` |
| `age`, `age_group` | int, category | возраст и группа `до 25 … 65+` |
| `experience_age_pedagogic_clean`, `experience_age_all_clean` | int | педагогический и общий стаж, лет |
| `experience_age_other_clean` | int | прочий стаж: неотрицательная разность очищенного общего и педагогического стажа |
| `category_qual_cat`, `category_due_clean` | str, float | категория (`высшая/первая/вторая/не_найдено`), год окончания её срока |
| `academic_degree_cat`, `sex`, `class_manager` | str, int, 0/1 | учёная степень, пол, классное руководство |
| `speciality` | str | направление деятельности (предмет), `не указано` — нет данных |
| **Мобильность** | | исход года Y по данным года Y+1; для 2024 — пусто (NaN) |
| `mobility_status` | Int8 | 0 — остался, 1 — перешёл в другую школу, 2 — ушёл из системы |
| `movement_type` | str | то же текстом: `остался` / `перешёл в другую школу` / `ушёл из системы` |
| `target` | float | исходная метка: 1 = ушёл из системы (совпадает с `mobility_status == 2`) |
| **Нагрузка** | | |
| `n_subjects`, `n_parallels`, `n_subject_parallel` | int | число предметов, параллелей, пар «предмет × параллель» |
| `min_parallel`, `max_parallel` | int | младшая и старшая параллель |
| `school_teachers`, `school_students` | int | педагогов школы в этом году, контингент школы (один срез из `Школы.xlsx`) |
| `students_per_teacher` | float | учеников на педагога; NaN, если штат школы выгружен не целиком |
| `school_staff_complete` | 0/1 | Эвристика: отношение учеников к педагогам ≤60; не подтверждённый реестр полноты штата |
| **Образование** | | по листу года из `Образование.xlsx` |
| `edu_higher` | 0/1 | есть высшее образование |
| `edu_pedagogical` | 0/1 | высшее педагогическое (вуз/специализация/квалификация содержит «педагог», «учитель», «преподав») |
| `edu_speciality_match` | 0/1/NaN | специализация соответствует предмету — эвристика по основам слов; NaN для неучителей и `не указано` |
| **Профразвитие** | | |
| `pk_recent` | 0/1 | ПК/ДПО за окно [Y−2, Y]; используются только сведения из выгрузок не позднее Y, неизвестная дата не считается событием |
| `pk_this_year` | 0/1 | есть запись в листе ПК-ПП этого года |
| `pk_hours_3y` | float | часы ПК/ПП за [Y−2, Y]; часы есть только в листах 2022–2024, поэтому для 2022 это 1 год, для 2023 — 2 года |
| `retraining` | 0/1 | профпереподготовка: ДПО со специализацией/квалификацией или тип `ПП` |

Текст «не указано» не считается наличием специализации или квалификации.
Полные технические повторы курсов удаляются; разные программы сохраняются.
Предельные часы p99 используются только в исследовательских графиках,
`pk_hours_3y` рассчитывается по полным часам. Граница системы для мобильности —
педагоги школ из предоставленного справочника; это отсутствие в следующем срезе
выборки, а не установленная причина увольнения.
